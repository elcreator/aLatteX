Document fields and template variables arrive in Latte as ordinary variables, which means they can be counted, split, filtered and compared rather than only printed. Three TVs are attached to this template: a text field, a multi-value checkbox, and an image.

Read this page's template

The sections around this text come from the template aLatteX Demo: Fields and TVs - Elements → Templates, category aLatteX demo; in the package it is demo/templates/tvs-and-fields.latte. The three TVs are under Elements → Template Variables: alxSubtitle, alxTags and alxImage. Find:

  • section #fields - {$pagetitle}, {$id}, {$published} and the rest, used as values: compared, formatted, tested, not merely echoed.
  • section #tvs - alxSubtitle read three ways, and alxTags split with |explode:'||' then looped. A multi-value TV is one string until something splits it, which is the whole reason this page exists.
  • alxImage is deliberately left empty, so the template can show a guarded read rather than printing an empty <img>.
  • section #documentobject - every field at once, and the shape a TV really has inside it: [name, value, display, display_params, type], not a bare string.
  • section #core - $evo, the core object itself, for the times a template needs to ask the CMS something.

The same values, live in this content field

Read here by the Evolution CMS parser rather than by Latte, which is the interesting part: the tag gives you the value and nothing else. Compare each line against what the template does with the same value.

  • Field: [*pagetitle*] → [*pagetitle*]
  • Field: [*id*] → [*id*], alias [*alias*]
  • Text TV: [*alxSubtitle*] → [*alxSubtitle*]
  • Multi-value TV: [*alxTags*] → [*alxTags*] - the values run together, because a tag hands you the CMS's display rendering of the TV, and a checkbox displays as its ticked values joined with nothing. Latte gets the stored string instead - look for Raw value: above, which prints evo||demo||raw from the same TV, and then splits it with |explode:'||'. Same value, two different things arriving.
  • Image TV, empty: [*alxImage*] → "[*alxImage*]". Nothing between the quotes, and no way to guard against it from a tag - the template can, with n:if.
  • Setting: [(site_name)] → [(site_name)]

Try it: edit this document, put something in Demo image, save, and watch the empty line above fill in while the template's guarded version starts showing its <figure>.
