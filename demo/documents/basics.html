Read this page's template

The sections above and below come from the template aLatteX Demo: Latte basics - Elements → Templates, category aLatteX demo; in the package it is demo/templates/basics.latte. Every value this page prints is set in that file, not here. Find:

  • near the top, {var $tags = ['latte', 'evo', 'demo']}, {var $price = 1234.5}, {default $heading = ...} and {varType string $pagetitle} - the four ways to introduce a variable.
  • section #printing - filter chains such as {$pagetitle|lower|firstUpper|truncate:20} and {$price|number:2, ',', ' '}.
  • section #branching - {if}, {elseif}, {switch}, and the same tests written as n:if attributes on the element itself.
  • section #loops - {foreach} with $iterator->first, {for}, {while}, n:foreach and n:inner-foreach.
  • section #blocks - {define alxNote, string $text, string $level = 'info'}, a block with named arguments, called three times with {include}.
  • section #control - {do}, {capture}, {spaceless} and {try}, the tags that produce no output of their own.

Latte stops before this field - proof

This paragraph lives in the resource's content, and content is not a template: aLatteX renders the template, and only then does Evolution CMS paste this text in at [*content*] and parse it. So the two syntaxes behave in opposite ways here, which is worth seeing once:

  • Latte, inert: {$pagetitle} prints as {$pagetitle}, and {$price|number:2} prints as {$price|number:2}. No error, no value - nothing ever compiled them.
  • EVO, live: [*pagetitle*] prints as [*pagetitle*], and [(site_name)] as [(site_name)].
  • Snippets run too: [[aLatteXDemoList? &items=`if||foreach||capture` &class=`alx-list`]]

Move the same line into the template and it flips: there {$pagetitle} is the one that resolves. If you want Latte to process a chunk after its pass is over, see the Chunks and snippets page.
